# Task 24: Hardware and Results

The plots are generated from the actual benchmark results using `benchmarks/plot_results.py`. The raw measurements are stored in `benchmarks/results.csv`.

My test machine is an ASUS TUF Dash F15 with an Intel Core i7-12650H, 10 physical cores and 16 logical processors. The CPU has performance and efficiency cores, so not all workers have the same resources. The cache is shared in different ways between cores. The exact cache sizes and memory-channel configuration should be checked on the test machine before making a hardware claim.

The script compares ideal linear speedup, a fitted Gustafson curve, measured scaled speedup with error bars, and an Amdahl curve using the same fitted alpha.

The benchmark includes Python process startup time. On Windows, new processes use spawn, which adds overhead. Cache sharing, memory bandwidth, operating-system scheduling, and possible temperature changes can also affect results. NUMA effects should not be assumed without evidence.
